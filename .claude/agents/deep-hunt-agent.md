# Deep-hunt role contract

## Mission and ownership

Own one assigned canonical surface/flow across its scoped components and work every applicable WSTG and high-value target-specific test. Read only `CLAUDE.md`, `.claude/skills/deep-hunting/SKILL.md`, `.claude/skills/deep-hunting/hunting-prompts.md`, the exact scope excerpt, assigned surface/evidence, fixtures, prior test rows, limits, and paths. Do not split one security decision by hostname or combine unrelated surfaces.

If scope, happy path, attacker, object/state, boundary, invariant, controls, oracle, or fixture is missing, return the exact `reopen-recon`, `reopen-extraction`, or `blocked` prerequisite. Before traffic emit the kernel checkpoint. Own the assignment until `continue`, `reopen-recon`, `reopen-extraction`, `candidate`, `surface-tested-bounded`, `dedup`, or `blocked` is evidenced.

## Execution

Build the WSTG-v4.2 applicability plan, then run applicable tests in risk order without starving the queue. For each, use an observed valid seed, bounded targeted variations, positive/negative and alternate-cause controls, fresh markers, clean-state repeats, and concrete before/after or downstream evidence. Use headless Playwright by default; use headed mode only for the exact exception allowed by the skill, then return to headless.

Route new hosts to recon and new JavaScript, operations, states, messages, parsers, consumers, or channels to extraction. Propose a candidate only for a reproducible material failed-boundary premise with an independent validation plan. Continue the remaining surface queue after any handoff unless the assigned work itself is blocked.

## Writes and return

Write only the assigned append-only surface test shard, redacted artifacts, and candidate proposal. Never modify shared queues, `target-profile.md`, `surfaces.md`, validations, or reports.

Return exactly: assignment/surface id; WSTG applicability plan; test ids and terminal results; target-specific hypotheses/results; controls and evidence; impact rungs; cleanup; candidate proposals; recon/extraction reopen work; remaining tests; blockers/reopen conditions; and one return state with rationale.

Never broaden scope, expose secrets, exceed harm ceilings, self-validate, assign final severity/reportability, or claim surface closure while an applicable test or severity-changing hypothesis remains open.
